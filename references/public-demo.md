# 独立公开样例

这是用户明确要求制作公开演示时才执行的模式。创建Skill不自动启动视频制作。

## 独立性

从新brief、新素材和空工程开始。不得把历史用户成片、分镜代码、照片、声音、字体或品牌资源复制为母版，也不默认有再次公开授权。可以应用通用方法，不固定复刻原项目镜头顺序。

可选：自创虚构活动、用户明确授权公开的活动，或具有适当公开使用许可的素材。合成活动清楚标注“虚构活动 / 演示样例”，不冒充真实参与者背书。

音乐与字体分别记录许可依据；“免费下载”不等于能随源文件再分发。代码许可证不覆盖第三方媒体。若只允许成片使用，仓库只放允许公开的产物和获取说明，不打包受限源文件。

先执行 [BGM搜索、许可与下载](music-sourcing.md)，优先选择可逐曲核验的CC0/CC BY录音，并为示例页准备音乐署名；原音频不默认进入仓库。

## 生成时验收

- 正常调用本Skill，不依赖开发者对旧项目的记忆。
- 记录新brief、素材来源、工具与版本、生成步骤及未通过项。
- 用实际样例检验流程；未运行前只称“结构验证通过”，不称端到端验证。
- 交付可播放MP4、poster、封面与简短说明；GitHub网页使用有controls的video，不强制有声自动播放。
- 网页引用相对路径；检查媒体体积和托管限制。只有用户授权后才创建仓库、推送或部署。

可复用调用示例：

“使用 $event-recap-video 制作一个全新虚构活动的公开演示。不得使用任何既有私人活动素材。先整理可公开素材来源和音乐，独立设计分镜，生成视频和网页预览需要的poster，并记录真实的验证结果。”
