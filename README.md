# Event Recap Video

### 把活动现场，剪成一条值得分享的视频。

面向沙龙、工作坊、社群聚会和会议的 **Agent Skill**。从活动资料、现场照片与音乐出发，独立设计分镜，制作回顾视频、适配封面和发布标题。

[开始使用](#开始使用) · [制作流程](#制作流程) · [公开样例](#公开样例) · [Skill 入口](SKILL.md)

> **当前状态**：已完成全新虚构活动样例的制作、导出与技术检查；人工听审尚未完成。本仓库不包含私人活动素材或固定视频母版。

## 开始使用

把本目录放入 Codex 技能目录：

```text
~/.codex/skills/event-recap-video/
```

新建会话，提供活动资料与素材，然后调用：

```text
使用 $event-recap-video 制作活动回顾视频。

素材：活动总结和现场照片。
音乐：请搜索适合活动的BGM，核验许可并推荐候选。
目标：突出现场交流，并讲清三个核心内容。
画幅：横屏；封面按实际上传位置分别适配。
先检查素材和音乐，再设计分镜并完成制作。
```

也可以只要求设计、分析或修改指定片段。已经确认的偏好会用于后续迭代。

## 制作流程

<img src="assets/readme/workflow.svg" width="100%" alt="制作流程示意：整理现场素材，围绕音乐设计分镜，交付视频与封面。此图不是成片样例。">

1. **整理现场**：提取活动事实，区分讲解、讨论、实操和表情素材。
2. **搜索并选择音乐**：根据氛围搜索曲目，核验具体许可，推荐试听并下载归档；用户也可以提供自己的音乐。
3. **围绕音乐编排**：先确定乐句和切点，再安排镜头、文字与动效。
4. **完成传播物料**：检查成片与声音，按实际裁剪框制作封面，配好标题。

## 三个重点

| 常见问题 | Skill 的处理方式 |
| --- | --- |
| 图片在动，节奏仍然慢 | 调整停留、镜头尺度与构图，避免每张图只做慢缩放 |
| 编号出现了，却没踩中鼓点 | 对齐重复节奏的同一位置，让照片、编号与标题同步落位 |
| 封面上传后被裁掉 | 先确认展示位置与裁剪比例，再重排文字和人物安全区 |

技术检查、关键帧检查和实际听看分别记录。自动节拍检测与频谱相似度只是辅助证据，不替代最终听审。

## 你提供什么，得到什么

**输入**：活动资料、现场照片或视频、品牌参考，以及发布位置。候选音乐可选；未提供时进入搜索选曲流程。缺失的信息先标注，不虚构现场成果。

**交付**：完整视频、可编辑工程、指定比例封面、推荐标题，以及素材来源、音乐署名、时间线和检查记录。每个项目独立设计，不预设品牌色、时长或镜头顺序。

## 环境与边界

这是工作流指令，需要能读取文件、编辑并导出视频的 Agent 环境。FFmpeg / ffprobe 可用于媒体检查；音乐分析、配音和图像生成工具按需使用。

- **动效能力**：内置八类动作规范与关键片段验证流程；按任务路由到已安装的 HyperFrames 动效/关键帧/组件库，或选择 huashu-motion 制作路线。艺术化片段可按需读取 huashu-art-motion。缺少这些技能时按内置规范实现，并明确能力差异；不捆绑第三方引擎和组件。
- **兼容范围**：提供 Codex 技能入口；其他客户端需按各自发现机制安装，尚未逐一验证。
- **真实人物**：优先用原图排版，检查人物裁切与面容变化。
- **公开发布**：生成文件不等于授权上传、推送或发布；第三方素材许可单独记录。

## 音乐如何选择

先按用途筛许可，再试听和分析节奏。公开样例优先考虑有明确依据的CC0或CC BY录音，Incompetech等站点作为检索入口；Pixabay、Jamendo等需额外核对平台或API条件。不是网站白名单，每次都要核验具体曲目。

默认不把BGM原文件放进Skill或公开仓库。自动下载受登录或验证码限制时提供官方曲目链接，用户下载后继续。本次样例已从 Incompetech 官方链接完成下载与许可记录；不承诺所有站点都能自动获取。

> 技术检查与关键静帧检查通过；人工正常速度听审未完成，同鼓声音色尚未确认。活动与人物为虚构演示，不代表真实活动成果。

